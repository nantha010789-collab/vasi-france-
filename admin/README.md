# VASI Admin Control Center

Production admin area for the VASI taxi platform.

## Modules
- Dashboard
- Bookings
- Live GPS
- Drivers
- Customers
- Cars
- Driver documents / KYC
- Pricing
- Driver commission
- Payments / refunds
- Promotions
- Support
- Revenue
- AI Assistant
- Settings / audit

The admin UI is designed to consume the existing Supabase schema. Do not place a Supabase service-role key in browser code; privileged operations must run server-side.
